Requirement R1

Reports Remediation — in detail

What we will fix

  • Wire Reports to global filter bar (warehouse, category, period)
  • Migrate from Options API to Composition API
  • Replace direct axios calls with api.js layer
  • Extract all hardcoded strings into i18n system
  • Remove console.log noise including render-time calls
  • Fix duplicate CSS declarations
  • Any additional defects found during full audit

Why this matters

The Reports page is the only view in the application that doesn't respond to the global filter bar. For a warehouse team that filters by location constantly, this makes it effectively unusable as a cross-warehouse comparison tool.

The i18n gap means Tokyo staff see English-only content on this page despite the rest of the application supporting Japanese.

Requirement R2

Restocking Recommendations — in detail

Stock analysis

Items at or below their reorder point are surfaced as candidates, ranked by how critical the shortage is relative to threshold.

Budget ceiling

Operators enter a spend limit. The system fills the list in urgency order until the budget is reached — ready to act, within authority.

Filter aware

Responds to warehouse and category filters so each location's team sees only their relevant items.

Urgency classification

High — below 50% of reorder point Medium — 50–80% of reorder point Low — 80–100% of reorder point

Requirement R3

Test coverage that unblocks IT

The absence of tests is the root cause of the current change freeze. We will deliver two layers of coverage:

Backend API tests

  • All endpoints with filter combinations
  • Edge cases: empty results, invalid IDs
  • Data type and structure validation
  • Budget ceiling arithmetic verification

Playwright end-to-end

  • Dashboard loads with correct summary data
  • Filter bar propagates across all views
  • Reports page renders and filters correctly
  • Restocking view and budget input
  • Orders and Inventory filter flows

Tests run with a single command. They will be committed to the repository and will continue to protect Meridian's codebase after this engagement ends.
