The Tokyo Commitment

Japanese localization is not a translation job

The Tokyo warehouse team of 12 has been working in an English-only interface since 2023. Most vendors will run strings through a translation API and call it done.

We won't. Our approach:

  • Proper keigo register (丁寧語) — business software uses polite-formal Japanese; machine-translated copy is immediately recognizable
  • Logistics-specific terminology — バックオーダー, 処理中, 納品済 — warehouse terms, not literal translations
  • Locale-aware formatting — Intl.NumberFormat('ja-JP'), 年月日 date order, 万-unit numerics
  • Nemawashi (根回し) review — draft locale shared with Tokyo team before formal review, so sign-off is a confirmation, not a discovery

品質

Quality (hinshitsu). In Japanese professional culture, a UI with awkward or incorrect language is not a cosmetic issue — it erodes trust in the system itself.

What this means for Meridian

The Tokyo team will receive a Japanese locale file reviewed by a Japanese-speaking team member, validated by Tokyo staff, using terminology the warehouse floor actually uses.

Not a translation. An adaptation.
