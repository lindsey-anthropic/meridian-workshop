Requirement R1

Reports Remediation — in detail

What we will fix

  • Wire Reports to global filter bar (warehouse, category, period)
  • Migrate from Options API to Composition API
  • Replace direct axios calls with centralised api.js layer
  • Extract all hardcoded strings into the i18n system
  • Remove console.log noise including render-time calls
  • Fix duplicate CSS declarations
  • All additional defects found during full audit

Why this matters

Reports is the only view that ignores the global filter bar — making cross-warehouse comparison impossible for the operations team.

The i18n gap means Tokyo staff see English-only content on this page despite the rest of the application supporting Japanese.
