# Pricing

**RFP #MC-2026-0417 — Meridian Components**
**Submitted by:** Capgemini

---

## Proposed Structure: Fixed Fee

We propose a fixed-fee engagement for the required scope (R1–R4), with a separately priced option for desired items (D1–D3). Fixed fee gives Meridian full budget predictability — a priority we noted in discussions with J. Okafor's team.

---

## Required Scope (R1–R4)

| Item | Description | Fixed Fee |
|------|-------------|-----------|
| R1 | Reports module remediation (full audit + all defect resolution) | $18,500 |
| R2 | Restocking recommendations (backend endpoint + frontend view) | $14,000 |
| R3 | Automated test suite (backend API + Playwright end-to-end) | $9,500 |
| R4 | Architecture documentation | $3,500 |
| **Total — Required** | | **$45,500** |

---

## Optional Scope (D1–D3)

| Item | Description | Fixed Fee |
|------|-------------|-----------|
| D1 | UI modernization (visual refresh, design system alignment) | $12,000 |
| D2 | Internationalization (i18n extension to remaining views) | $7,500 |
| D3 | Dark mode (operator-selectable theme) | $5,000 |
| **Total — Optional** | | **$24,500** |

---

## Not-to-Exceed

Should Meridian prefer a T&M structure, our not-to-exceed for the full engagement (R1–R4 + D1–D3) is **$72,000** at a blended rate of **$175/hour**.

---

## Payment Milestones (Fixed Fee)

| Milestone | Amount |
|-----------|--------|
| Contract signing | 25% — $11,375 |
| Phase 1 complete (audit report delivered) | 25% — $11,375 |
| R1–R3 complete and accepted | 35% — $15,925 |
| Final delivery and handoff | 15% — $6,825 |

---

## Inclusions and Exclusions

**Included:**
- All development, testing, and documentation work described in §Technical Approach
- Weekly status reports
- Handoff session with Meridian IT
- 30-day post-delivery support for defects introduced by our work

**Excluded:**
- Infrastructure, hosting, or cloud costs
- Third-party software licenses
- Database migration or external system integrations
- Work outside the scope defined in this proposal

---

## Assumptions

1. Pricing assumes the codebase is materially consistent with what we reviewed pre-proposal. Significant undisclosed complexity will be assessed and communicated before proceeding.
2. Desired items (D1–D3) pricing is contingent on R1–R4 scope being unchanged. Changes to required scope may affect optional pricing.
3. Travel to Meridian facilities is not anticipated; all work is delivered remotely.
