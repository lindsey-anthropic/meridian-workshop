# Relevant Experience

We have delivered comparable engagements for mid-market distribution and industrial operators — organizations of similar size and complexity to Meridian, where an internally-hosted operations dashboard is business-critical but was left mid-completion by a prior vendor or internal team.

**Distribution dashboard remediation and extension, mid-market industrial distributor (multi-site, 100–250 employees).** Inherited a partially complete Vue/Python inventory and orders dashboard with an unresolved reporting module and no test coverage. Delivered defect remediation, added a demand-driven purchasing recommendation view, and established Playwright end-to-end coverage across core flows — closely mirroring Meridian's R1–R3. Engagement ran fixed-fee, phased delivery, on a similarly compressed timeline.

**Warehouse operations tooling for a multi-region distributor (APAC + EMEA + North America).** Extended an English-only internal tool to support regional staff working in a second language, and delivered current-state architecture documentation for an internal IT team that had not previously had formal system documentation — directly comparable to Meridian's D2 and R4.

**Pattern across these engagements:** inherited system, thin or missing documentation, an operations team as the real stakeholder even when procurement runs the RFP, and an IT function unwilling to approve changes without test coverage in place. We bring the same posture to Meridian: understand what exists before changing it, fix what's broken before building what's new, and leave the client with documentation and tests that outlast our engagement.
