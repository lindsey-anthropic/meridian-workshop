# Pricing

We propose a **fixed-fee engagement, billed by phase**, prioritizing cost and schedule predictability — consistent with what matters most to Meridian's procurement process. Required scope (R1–R4) is a committed, fixed price. Desired scope (D1–D3) is priced separately as options Meridian can accept or decline without affecting the required delivery.

## Required scope (R1–R4) — fixed fee

| Phase | Scope | Fee |
|---|---|---|
| 0 — Onboarding & Architecture Review | R4 | $6,000 |
| 1 — Reports Remediation | R1 | $10,000 |
| 2 — Restocking Recommendations | R2 | $24,000 |
| 3 — Automated Browser Testing | R3 | $10,000 |
| **Total (required)** | | **$50,000** |

## Desired scope (D1–D3) — priced options

| Item | Scope | Fee |
|---|---|---|
| D1 | UI modernization | $9,000 |
| D2 | Internationalization (remaining modules) | $6,000 |
| D3 | Dark mode | $4,000 |
| **Total (if all selected)** | | **$19,000** |

## Assumptions

- Pricing assumes the current stack (Vue 3, FastAPI, JSON-file data layer) is retained; no database migration or infrastructure change is in scope.
- Fees are fixed per phase; work beyond the described scope of a phase (e.g., new requirements discovered mid-engagement) would be scoped and quoted separately, not absorbed into the fixed fee.
- Milestone acceptance (per the Timeline) gates phase completion and invoicing.
- Total possible engagement value: **$50,000–$69,000** depending on which, if any, desired items Meridian selects — within the $45–65k range we'd expect for an engagement of this scope at Meridian's size.
