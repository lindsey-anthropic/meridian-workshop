# Pricing

**Proposal in response to RFP #MC-2026-0417**

---

We are proposing a fixed-fee engagement for the R1–R4 scope, priced by phase. Fixed-fee provides Meridian with budget predictability; the phase structure means each fee is tied to a concrete deliverable and milestone sign-off.

---

## Base Engagement — R1 through R4

| Phase | Scope | Fee |
|---|---|---|
| Phase 1 — Onboarding & Audit | Defect catalogue, architecture draft, test harness | $9,500 |
| Phase 2 — Reports Remediation | R1 complete, R3 (Reports flows) | $14,000 |
| Phase 3 — Restocking Feature | R2 complete, R3 (Restocking flows) | $16,500 |
| Phase 4 — Completion & Handoff | R3 complete, R4 final, handoff package | $9,000 |
| **Total (R1–R4)** | | **$49,000** |

The total sits within the mid-range of Meridian's indicated budget. We have not compressed scope to hit a number — the phase fees reflect realistic estimates for the work described in the technical approach.

---

## Payment Schedule

| Milestone | Amount |
|---|---|
| Contract execution | $12,250 (25%) |
| Phase 1 complete — defect catalogue and test harness accepted | $12,250 (25%) |
| Phase 2 complete — Reports sign-off | $12,250 (25%) |
| Phase 4 complete — final delivery accepted | $12,250 (25%) |

Invoices are net-30. We do not charge for Phase 3 at a separate milestone — that fee is collected at final delivery, which aligns our incentive to ship the Restocking feature with Meridian's incentive to accept it.

---

## Desired Items — D1, D2, D3

D1 (UI modernisation), D2 (internationalisation), and D3 (dark mode) are not included in the base fee above. As noted in the technical approach and timeline, D1 is dependent on receipt of Meridian's brand guide, and all three items carry scope that cannot be reliably estimated from the RFP alone.

We recommend scoping these as a follow-on phase once the base engagement is underway. Indicative ranges, subject to confirmed scope:

| Item | Indicative Range | Key Dependency |
|---|---|---|
| D1 — UI Modernisation | $6,000 – $10,000 | Brand guide receipt |
| D2 — Internationalisation | $5,000 – $8,000 | Translation strings from Meridian |
| D3 — Dark Mode | $3,500 – $5,500 | None |

These ranges assume the base engagement is complete and the codebase is in a clean, well-tested state. Working on a stabilised codebase is faster than working on the current one.

---

## Assumptions & Exclusions

- Pricing assumes remote delivery. On-site travel, if required, would be scoped and invoiced separately.
- Deployment, hosting, and infrastructure changes are out of scope.
- Prices do not include third-party software licences or services.
- If the Phase 1 defect audit reveals Reports module issues substantially beyond what the RFP describes, we will notify Meridian before proceeding and propose a scope adjustment if warranted. We will not absorb material undisclosed work silently, and we will not bill for it without agreement.
